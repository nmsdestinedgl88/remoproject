================================================================================
PRODUCT SHOTS: HTML/CSS/JS + JAVA2D/JAVACV RENDERING GUIDE
================================================================================
GROUP A: FULLY RENDERABLE (66%) - High Fidelity Recreation
GROUP B: PARTIALLY RENDERABLE (23%) - Stylized Approximation Required
================================================================================

APPROACH KEY:
  [HTML]  = HTML + CSS + JS (browser, real-time)
  [J2D]   = Java2D (headless/server batch)
  [JCV]   = JavaCV + FFmpeg (video export wrapper)
  [BOTH]  = Both viable; selected best noted with reason

SECTION 1: ANGLES & PERSPECTIVES (10 Shots)
--------------------------------------------------------------------------------

1. EYE-LEVEL SHOT
   Best Approach: [HTML]
   HTML: flex container + `align-items: center; justify-content: center;`
   Java Alternative: J2D `Graphics2D.drawImage()` at centered coords.
   Why HTML: GPU compositing, zero frame cost.

2. HIGH ANGLE (TOP DOWN)
   Best Approach: [HTML]
   HTML: `perspective: 1000px; transform: rotateX(60deg);`
   Java Alternative: J2D `AffineTransform` with shear matrix.
   Why HTML: True perspective via GPU, cheaper than manual matrix math.

3. LOW ANGLE
   Best Approach: [HTML]
   HTML: `perspective: 800px; transform: rotateX(-30deg);`
   Java Alternative: J2D `AffineTransform.getShearInstance()`.
   Why HTML: Hardware perspective.

4. DUTCH ANGLE
   Best Approach: [HTML]
   HTML: `transform: rotate(15deg);`
   Java Alternative: J2D `AffineTransform.getRotateInstance()`.
   Why HTML: Declarative, GPU-accelerated.

5. BIRD'S EYE VIEW
   Best Approach: [HTML]
   HTML: `perspective: 1200px; transform: rotateX(90deg) scale(0.9);`
   Java Alternative: J2D combined scale + shear.
   Why HTML: Single-line transform.

6. PROFILE SHOT
   Best Approach: [HTML]
   HTML: `object-fit: contain;` no transform.
   Java Alternative: J2D direct draw.
   Why HTML: Trivial.

7. HERO SHOT
   Best Approach: [HTML]
   HTML: flex center + radial-gradient + `filter: drop-shadow()`.
   Java Alternative: J2D `RadialGradientPaint` + `ConvolveOp` shadow.
   Why HTML: GPU blur, one-line filter.

8. REVERSE ANGLE
   Best Approach: [HTML]
   HTML: `transform: scaleX(-1);`
   Java Alternative: J2D `AffineTransform.getScaleInstance(-1, 1)`.
   Why HTML: One line.

9. THREE-QUARTER ANGLE
   Best Approach: [HTML]
   HTML: `perspective: 1000px; transform: rotateY(45deg) rotateX(-10deg);`
   Java Alternative: J2D 3D matrix manually.
   Why HTML: Native 3D transform.

10. WORM'S EYE VIEW
    Best Approach: [HTML]
    HTML: `perspective: 800px; transform: rotateX(-60deg);`
    Java Alternative: J2D shear + scale.
    Why HTML: Perspective shortcut.

    Best Approach: [HTML] for browser playback / [JCV] for MP4 export
    HTML: CSS `@keyframes steps()` OR JS `setInterval` source swap.

    Why: HTML for delivery; JCV when final artifact must be MP4.
