VIDEO STYLE SCREENING FOR LLM-CODABLE HTML/CSS/JS
================================================================================
Question: Which video styles can be coded by an LLM in HTML/CSS/JS — either
fully or partially — where images are provided externally?

VERDICT KEY
-----------
[FULL]     LLM can code the entire thing (shapes, SVG, CSS filters, canvas,
           typography, animation). Only static images supplied as inputs.
[PARTIAL]  LLM handles layout, motion, compositing, grading; the visual "look"
           depends on supplied raster art / textures / frames.
[ASSET]    Style identity is photographic/rendered craft; only sequencing is
           codeable.

================================================================================
DETAILED BREAKDOWN — TOP 9 STYLES (from follow-up request)
================================================================================

1. CINEMATIC  —  [FULL] (with supplied stills)
   - Letterbox bars (aspect-ratio + black bands)
   - Anamorphic feel: contrast/saturate filters + subtle chromatic aberration
   - Ken Burns pans/zooms via transform + @keyframes
   - Color grading via filter: sepia() hue-rotate() contrast()
   - Vignette via radial-gradient overlay
   - Shallow depth-of-field via backdrop-filter: blur()

2. COMMERCIAL  —  [FULL]
   - Product card layouts (CSS Grid)
   - Snappy transitions (cubic-bezier easing)
   - Text pop-ins, price tags, CTA buttons
   - Logo stings via SVG stroke-dasharray animation
   - Bright saturated palette — pure CSS

3. KINETIC TYPOGRAPHY  —  [FULL] (perfect LLM target)
   - 100% text + timing + transforms
   - @keyframes for scale, rotate, skew, clip-path reveals
   - Variable font weight animation (font-variation-settings)
   - Masked text reveals via clip-path or background-clip: text
   - Split-text animation via JS
   - No images required

4. DOCUMENTARY  —  [PARTIAL]
   - Codeable: Ken Burns, lower-thirds, chapter cards, interview framing,
     grain overlay (feTurbulence), desaturated grade
   - Needed: actual photographs/footage

5. EXPLAINER  —  [FULL] (with icon set)
   - Scene sequencing, step reveals, callout lines
   - SVG icon animation (drawing, morphing)
   - Number counters, progress bars, arrow/path animations
   - Needs only simple icons — easily supplied or drawn in SVG

6. MINIMALIST  —  [FULL]
   - Whitespace, simple geometry, restrained motion
   - Thin type, limited palette, slow eases
   - Pure CSS/SVG

7. COLLAGE  —  [PARTIAL]
   - Codeable: layered transforms, rotation, blend modes
     (mix-blend-mode: multiply/screen), torn-paper masks via clip-path,
     drop shadows, staggered timing
   - Needed: the cutout images themselves

8. HANDDRAWN  —  [PARTIAL] (borderline FULL)
   - Codeable: "boil" wiggle via feTurbulence + feDisplacementMap animated,
     rough SVG strokes, frame jitter on loop
   - Needed: ideally a set of hand-drawn frames — but a single SVG traced
     image can be made to feel hand-drawn with filters

9. MOTION GRAPHICS  —  [FULL]
   - Shapes, masks, transitions, morphs
   - SVG path animation, clip-path wipes
   - Particle canvas, easing, timing
   - Entirely codeable

================================================================================
RULE OF THUMB
================================================================================
- The more a style is defined by geometry, typography, timing, color, or CSS
  filters                                      ->  [FULL]
- The more it depends on hand-drawn frames, painted textures, or photographic
  craft                                        ->  [PARTIAL]
- Nothing on the list is fully un-codeable — but roughly two-thirds need
  supplied raster assets to look authentic.

PIPELINE GUIDANCE
-----------------
- Treat [FULL] styles as "generate from scratch."
- Treat [PARTIAL] styles as "generate the animator, ingest your frames."
