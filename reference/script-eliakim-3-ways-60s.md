2. **40% in 60 days:** is it a total return over 60 days (not yearly), does it include the capital back, and is it fixed or a target? "Guaranteed" is not used anywhere.

4. **Farm gate rates:** the video uses the term without explaining it. Say if you want a short plain definition on screen.
5. **Way three:** does the customer set the price, or does Eliakim deliver at farm gate rates whatever price is written? The script says both, as in the brief. Please clear this up.
6. **Way two:** are there minimum volumes or milling fees to show?
7. **Call to action:** phone, link or QR.
